Privacidade

Os dados que preenches no pedido são utilizados para identificar-te, responder ao teu contacto e combinar a encomenda, entrega e pagamento. Ao enviares o pedido, estes dados são transmitidos ao WhatsApp.

A data de aniversário é opcional. Só a incluiremos no pedido se a indicares e assinalares o consentimento. Serve para o benefício especial de aniversário. Não introduzas dados que não sejam necessários para tratar o pedido.

Para esclarecer dúvidas ou pedir a remoção dos dados partilhados connosco, contacta a Iracema's Beauty pelo WhatsApp.
